# Replace BEST-NL with NovaPolicy

## Context and problem
BEST-NL blocks SG-1 and SG-2. EP-01 asks for buy before make.

## Considered options
1. Modernise BEST-NL.
2. Standard package (three vendors evaluated, NovaPolicy best fit for Swiss non-life).

## Decision
Option 2, NovaPolicy as vendor SaaS.

## Consequences
Investment approved by the executive board on 2026-01-28 (portfolio decision PF-2026-03,
see FINDINGS F6). Vendor dependency accepted (R-NOVA-01).
