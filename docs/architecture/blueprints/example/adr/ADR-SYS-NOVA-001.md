# Vendor SaaS in Swiss region

## Context and problem
NovaPolicy is offered as SaaS or on-premise. On-premise upgrades are slow and costly.

## Decision
SaaS in the vendor's Swiss region (STD-DAT-01), with FINMA outsourcing assessment (STD-OUT-01).

## Consequences
Faster upgrades, less operational effort; dependency on vendor operations, exit plan required.
